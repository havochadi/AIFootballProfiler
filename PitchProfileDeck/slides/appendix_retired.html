Appendix · PitchProfile · AAI3001

34

About 40 seconds, only if asked. This is the list of things we built and then set aside, so the main slides describe only what the system does today. The shot classifier and the hand-written shot rule were replaced by the T-DEED video spotter: on the same four unseen halves the spotter scored F1 0.70 against 0.41 for the classifier. The re-identification head was replaced by the CLIP identity model, 90.1% against 71.6% appearance matching. The fine-tuned ball detector finds more balls on its own, 59% against 47%, but credited fewer passes end to end, 26.2% against 34.2% right, so the default detectors stay. A second, tackle-weighted spotter fine-tune did not help. The short-clip upload, manual calibration and the YOLO11n detector were removed because the models are built and tested on whole halves and matches. The archetype profiler and rating screens were removed because no player was ever labelled.
