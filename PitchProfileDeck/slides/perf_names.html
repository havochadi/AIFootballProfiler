Accuracy against coverage

Model: fine-tuned CLIP ViT-B/16 identity model, 13,610 tracklets from 3 unseen games

What it means

Raising the confidence bar trades coverage for accuracy. A number is read confidently for only about 4 in 10 tracklets, so appearance matching (98% right) names the rest once a number has anchored the player.

About 55 seconds. Left: a confusion matrix for the shirt-number reader on the official SoccerNet Jersey test, 1,211 tracklets, of which 856 show a readable number and 355 do not. When a number is visible the reader gets it right 73.5% of the time, says "not visible" for 20% and reads a wrong number for 6.5%. When no number is visible it correctly says so 88.5% of the time and invents a number 11.5% of the time. So the dominant failure is silence, not error, which is the safe direction. This run scores 77.9% overall; the main evaluation of the same reader scored 80.3%, so the two runs differ by about two points. Right: the trade-off curve. For our fine-tuned identity model, each point is a confidence bar. If we only accept number readings above 0.5 confidence, 38% of tracklets get a reading and 94% of those are right. Appearance matching, which compares a tracklet with the players already numbered, is right 98% of the time even when forced to answer for every tracklet. That is why the system reads a number when it can, and lets appearance carry the player the rest of the time. Models: the matrix is the ResNet-34 legibility classifier plus the PARSeq reader; the curves are the fine-tuned CLIP ViT-B/16 identity model, its number-reading head and its appearance embedding.
